================================================================================
  PORTFOLIO IMAGE PLACEMENT GUIDE
  Dakshesh Sharma — Portfolio Website
================================================================================

This file tells you EXACTLY where to put your personal images so the
portfolio website renders them correctly. Filenames are case-sensitive.

--------------------------------------------------------------------------------
  1. PROFILE / HERO IMAGE
  Path:  public/images/profile.jpg
  Use:   A clean portrait of you (preferably with a clean background or
         transparent PNG). Used in the Hero section and the About section.
  Recommended: 800x800px (square) or 600x800px (portrait), JPG/PNG/WEBP.
--------------------------------------------------------------------------------
  2. ABOUT SECTION PHOTO
  Path:  public/images/about.jpg
  Use:   A more casual / candid shot for the "About" section.
  Recommended: 900x1100px (portrait), JPG/PNG/WEBP.
--------------------------------------------------------------------------------
  3. PROJECT SCREENSHOTS
  Path:  public/images/projects/
  Use:   One cover image per project (currently 6 projects).

  Required filenames:
    public/images/projects/vr-driving-sim.jpg
    public/images/projects/crypto-volatility.jpg
    public/images/projects/landscape-skill-gap.jpg
    public/images/projects/customer-segmentation.jpg
    public/images/projects/olympic-analysis.jpg
    public/images/projects/excel-dashboard.jpg

  Recommended: 1600x1000px (16:10) for best card fit. JPG/PNG/WEBP.
--------------------------------------------------------------------------------
  4. EXPERIENCE / COMPANY LOGOS
  Path:  public/images/experience/
  Use:   Small square logos for the experience timeline (optional — the
         site falls back to text initials if missing).

  Optional filenames:
    public/images/experience/niqo-logo.png
    public/images/experience/securin-logo.png
    public/images/experience/upraised-logo.png

  Recommended: 256x256px transparent PNG.
--------------------------------------------------------------------------------
  5. CERTIFICATION IMAGES
  Path:  public/images/certs/
  Use:   Certificate badges or course thumbnails (optional — the site
         renders an icon-based card if missing).

  Optional filenames:
    public/images/certs/google-advanced-data-analytics.png
    public/images/certs/data-analysis-python.png
    public/images/certs/algorithms-stanford.png

  Recommended: 512x512px PNG.
--------------------------------------------------------------------------------
  6. ACHIEVEMENT / TROPHY IMAGES
  Path:  public/images/achievements/
  Use:   JEE Mains scorecard or trophy photo (optional — the site renders
         a numeric showcase if missing).

  Optional filenames:
    public/images/achievements/jee-scorecard.png

  Recommended: 1200x800px JPG/PNG.
--------------------------------------------------------------------------------

================================================================================
  FALLBACK BEHAVIOUR
================================================================================
If a file is missing, the website will still render correctly — it will use:
  - Gradient placeholders for project covers
  - Text initials for company logos
  - A styled icon for certificate cards
  - Animated number counters for achievements

So you can ship the site WITHOUT any images and add them later.

================================================================================
  OPTIMISATION TIPS
================================================================================
- Use https://tinypng.com or https://squoosh.app to compress images before
  uploading (target < 300KB per image).
- Prefer WEBP format for ~30% smaller file sizes at the same quality.
- Use descriptive alt-text in src/data/portfolio.jsx when adding projects.
